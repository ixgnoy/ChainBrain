PROPOSED CLEAN CHAIN for tools/voice.py  (not applied; tools/voice.py is untouched)
ffmpeg 9.0.1 as installed here; every filter below exists in it and parsed/ran in the test.

CURRENT (voice.py line 53)
  highpass=f=80,afftdn=nf=-28,acompressor=threshold=-22dB:ratio=2.5:attack=8:release=140:makeup=2

WHY IT NEEDS CHANGING
  - afftdn nf=-28 tells the denoiser the room is at -28 dBFS. A quiet room on a phone is about -50 to -45 dBFS, so
    the estimate is 20 dB off: it either does little or (with tn) chases the wrong floor. Set nf near the real floor.
  - nothing removes the pauses' hiss/hum after compression; the compressor then lifts the noise (makeup=2).
  - no de-ess, no tone shaping, no limiter after the makeup gain.

PROPOSED (one line, drop-in for CLEAN)
  highpass=f=90:poles=2,afftdn=nr=14:nf=-46:tn=1:tr=1,agate=threshold=0.004:ratio=1.8:range=0.18:attack=12:release=260:knee=3,equalizer=f=200:t=q:w=0.9:g=-1.5,equalizer=f=3200:t=q:w=1.1:g=2,deesser=i=0.4:m=0.5:f=0.5:s=o,acompressor=threshold=-24dB:ratio=2.5:attack=10:release=160:makeup=3,alimiter=limit=0.89:attack=3:release=50

What each stage does
  highpass f=90 poles=2   rumble, handling thumps, AC. 90 suits most voices; use 70-80 for a deep voice.
  afftdn nr=14 nf=-46 tn=1 tr=1
                          FFT denoise. nr = reduction in dB (12 default; keep 12-18, above ~20 the voice goes watery).
                          nf = noise floor in dBFS: SET IT FROM THE RECORDING (command below). tn=1 tracks changes,
                          tr=1 adds residual-noise tracking.
  agate threshold=0.004 ratio=1.8 range=0.18 ...
                          gentle downward expander, not a hard gate: pauses drop ~15 dB, tails are not chopped.
                          threshold 0.004 = -48 dBFS; raise to 0.006-0.008 if the room is noisier than -45 dB, lower to
                          0.002 if the speaker is quiet (peaks below -20 dBFS). Never range below 0.1 (breathing/choppy).
  equalizer 200 Hz -1.5   removes proximity/room mud (phone near the mouth, small room). Skip if the voice sounds thin.
  equalizer 3.2 kHz +2    presence/clarity for laptop speakers.
  deesser i=0.4 m=0.5 f=0.5 s=o
                          ffmpeg's deesser: i=intensity 0-1 (0.35 = about -4 dB on the worst sibilants, 0.6 = -10 dB, likely to dull
                          the 's' (not auditioned; stay at or below 0.5)), m=max reduction, f=frequency (0.5 default),
                          s=o = output the full (de-essed) signal; s=s is not accepted by this build.
  acompressor 24 dB 2.5:1 gentle levelling (mix.py levels each line afterwards, so this only evens words within a line).
  alimiter 0.89           catches the makeup gain's peaks (-1 dBFS).

NO loudnorm IN CLEAN on purpose: voice.py cleans whole section files and cuts lines afterwards; tools/mix.py already levels
every line to -19 dB RMS and the final mix gets two-pass loudnorm to -14 LUFS. A per-file loudnorm here would only shift
what mix.py then re-levels, and one-pass loudnorm pumps. (For a standalone voice file, loudnorm=I=-16:TP=-1.5:LRA=7
at the very end is the usual podcast value; -14 for a final stereo master.)

SET nf FROM THE REAL FILE (10 s of room tone at the start of each take)
  ffmpeg -ss 0 -t 3 -i footage/voice/01-hook.m4a -af volumedetect -f null - 2>&1 | grep -E 'mean_volume|max_volume'
  use nf = mean_volume - 1 (e.g. -47 dB -> nf=-48). Stay within -55..-35.
  Tell the owner to leave 3 s of silence at the start of each file (also gives afftdn its first noise estimate).

OPTIONAL NEURAL STAGE (not installed here, not tested): only if the real recording is noisy (a fan, traffic) after the above.
  1) RNNoise via ffmpeg arnndn: needs a model file from the rnnoise-models repo (e.g. bd.rnnn, "beguiling-drafter",
     GregorR/rnnoise-models). Insert after highpass:  arnndn=m=/path/bd.rnnn:mix=0.85
     Use it INSTEAD of afftdn, not on top (two denoisers = underwater sound). mix<1 keeps some natural air.
  2) DeepFilterNet (Rikorose/DeepFilterNet): CLI `deep-filter` reads only 48 kHz WAV:
       ffmpeg -i rec.m4a -ar 48000 -ac 1 rec48.wav && deep-filter -o cleaned/ rec48.wav
     then run the chain above WITHOUT afftdn. Treat the model/binary as untrusted download: ask before fetching.
  Neither removes room reverb: only a closet/duvet does that.
