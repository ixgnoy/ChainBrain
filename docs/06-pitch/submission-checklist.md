## In one minute

- **Required (3):** technical document, presentation deck (up to 10 minutes), demo video (up to 5 minutes). **Optional (3):** source code, security self-assessment, execution evidence. We send all six. Reason: Topic F is judged on tx hashes (Task 40) and the self-assessment is where Security 30 is shown, and the first cut (top 10, 22-23 Oct) is made from what we submit ([how judges score](how-judges-score.md)).
- **Everything in English**, with the official templates. The rules say submitted materials "must include an English version" and the Chinese rules text prevails if the two versions differ ([rules](../01-competition/hackathon-rules.md)).
- **Deadline:** 24:00 on 20 Oct 2026, UTC+8 (the spec says 23:59; we plan to the earlier one). **Our own deadline: submit the full package by 12:00 on 20 Oct (UTC+8)**, after a complete "v1" dry submission on the night of 19 Oct if the organisers allow resubmission [VERIFY].
- **Unknown, ask the organisers** (the email draft is in [open questions](../00-start-here/open-questions.md)): how to send the package (email address and subject format, upload link), file-size limits, number of allowed resubmissions, whether the deck is recorded or live, whether testnet hashes count.
- **Each member prepares now:** passport (type and number), proof of enrolment (in English), university, major, year, email, phone. The team needs at least 60% non-Chinese nationals (3 of 5, 3 of 4, 2 of 3, 2 of 2).
- **Evidence is the centre:** the execution evidence file is generated by `npm run evidence` and the red-team numbers by `npm run redteam` ([design](../05-security/evidence-and-redteam-harness.md)). Never hand-type a hash.
- **Never put** passport scans, keys, `.env` files or personal data in the repo, the video or any document.

## 5. Final checks before sending

- [ ] All six deliverables present, English, template headings kept, team name, track and date filled on every document.
- [ ] Every number in the docs is copied from `evidence.md` or `report.md` of the final commit, with the commit hash printed beside it.
- [ ] Every hash link opens on the explorer and shows the expected status (success, or failed for the intentional reverts).
- [ ] Video: under 5:00 by the player's clock, 1080p, subtitles, readable hashes, no secrets or personal data, no copyrighted music.
- [ ] Deck: 10-minute rehearsal timed; no Chinese placeholder text left.
- [ ] Repo: tagged commit, README in template, `.env.example` only, no keys in history, licences listed, fresh-clone run works.
- [ ] Claims match enforced behaviour (no "None known", no "ERC-4337 account" unless true, no "nobody verifies buyer agents").
- [ ] Files named with the common prefix; PDFs of the DOCX/PPTX files attached as a safety copy; each file opens.
- [ ] Sent from the team's shared mailbox with the leader and one other member in copy; receipt or sent-mail screenshot saved.
